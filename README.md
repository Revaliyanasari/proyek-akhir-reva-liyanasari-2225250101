# Generator Soal Aritmetika Berbasis Python

## 1. Deskripsi Proyek

Generator Soal Aritmetika adalah proyek pemrograman sederhana menggunakan bahasa Python yang dirancang untuk membantu pengguna berlatih operasi hitung dasar secara interaktif.

Program ini direncanakan dapat menghasilkan soal secara acak, menerima jawaban pengguna, memeriksa kebenaran jawaban, dan menampilkan rekap hasil latihan.

## 2. Tujuan

- Membantu pengguna berlatih operasi hitung dasar.
- Menerapkan konsep algoritma dan pemrograman menggunakan Python.
- Mengembangkan program sederhana yang dapat memeriksa jawaban dan menghitung nilai latihan.

## 3. Fitur yang Direncanakan

1. Memilih operasi penjumlahan, pengurangan, perkalian, atau pembagian.
2. Menghasilkan soal aritmetika secara acak.
3. Menerima jawaban dari pengguna.
4. Memeriksa kebenaran jawaban.
5. Menghitung dan menampilkan nilai akhir latihan.

## 4. Teknologi yang Digunakan

- Bahasa pemrograman Python.
- Visual Studio Code sebagai editor kode.
- Git untuk pengelolaan versi.
- GitHub untuk penyimpanan repositori proyek.
